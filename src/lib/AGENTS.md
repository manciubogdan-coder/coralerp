- Prereception lines close by receipt or by `missing_at` (goods on documents that never arrived); all-closed with any missing → status `lipsa`, treated as closed everywhere via `CLOSED_STATUSES` in `src/lib/prereceptie.ts`, and missing lines never count as expected stock. Why: documents must close without faking a receipt, and absent goods must stay visible.
- Missing prereception goods appear as `is_missing` rows on their reception document (report, history, Excel, manual and scheduled supplier emails) via `supabase/functions/_shared/prereceptieMissing.ts`: day = latest receipt of the same prereception, else expected date; document = the one holding those receipts, else same doc number. Why: everyone sees on the document what should have come, consistently.
